### Owllarプラットフォームの効果

```
Before Owllar:
  仕入れ = プロ卸市場 → 高コスト（卸マージン乗せ）

After Owllar:
  仕入れ = 個人から直接買取（C2B） → ▲5-10%/台のコスト削減

  Owllar機能:
  ① 時計オーナーが市場需要・価格をリアルタイム確認
  ② アプリから直接RASINに売却可能
  ③ AI（アント社内チーム開発）による価格最適化
```

## リターン分解

```
MOIC ~3.5x の分解:

① 売上成長（100億→200億、2.0x）        → 主ドライバー
② EBITDA成長（10億→22億、2.2x）        → Owllarによる仕入れコスト改善
③ マルチプルは若干縮小（6.0x→4.8x）     → 高級品市場の一部減速
④ レバレッジ効果                          → 50/50構造の恩恵
```

### マルチプル縮小にもかかわらず3.5xを実現
- 入口6.0x → 出口4.8x（マルチプルは▲20%縮小）
- しかし、EBITDA 2.2x成長 + レバレッジ効果で **MOIC 3.5xを達成**
- **教訓**: マルチプル拡大がなくても、利益成長とレバレッジで十分なリターンは出せる

## アントの差別化: 社内DXチーム

### 他PEファンドとの違い
- アントは**社内にAI/DX専門チーム（4名）**を保有
- 外部のコンサルやSIerではなく、ファンド自身がDXツールを開発・実装
- Owllarはアントの社内チームが企画・開発したプロダクト

### DX投資のポイント（NSSK ぶんか社との比較）

| 項目 | ぶんか社（NSSK） | RASIN（アント） |
|------|-----------------|----------------|
| DX対象 | コンテンツ配信 | 仕入れ（調達） |
| DX人材 | 外部採用（楽天15名） | 社内チーム（4名） |
| 効果 | マージン +13-16pt | 仕入れコスト ▲5-10% |
| MOIC | ~3x | ~3.5x |
