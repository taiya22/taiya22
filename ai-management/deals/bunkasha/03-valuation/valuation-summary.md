# バリュエーション & リターン分析: ぶんか社

## Entry Valuation（2017年4月）

| 項目 | 推定値 |
|------|--------|
| Entry EV | 15-20億円（推定） |
| EBITDA | 1-2億円（マージン2-4%） |
| Entry EV/EBITDA | 10-15x（低EBITDAのため高マルチプル。実質的にはIP価値で投資判断） |

### エントリーの考え方
- 通常のEBITDA倍率では判断困難（低マージンのため）
- **IPライブラリーの資産価値**をベースに投資判断
- DX成功後のEBITDAポテンシャルから逆算したバリュエーション

## バリューアップ実績: DXによるマージン劇的改善

| 指標 | Entry（2017） | Exit（2020） | 変化 |
|------|-------------|-------------|------|
| EBITDAマージン | 2-4% | **15-20%** | **+13-16pt** |
| デジタル売上比率 | 僅少 | **過半** | 構造転換 |
| デジタルチーム | 0名 | 15名 | 楽天等から採用 |

### マージン改善の源泉
```
紙媒体のコスト構造:
  印刷費 + 製本費 + 物流費 + 返品処理 → 高コスト → マージン2-4%

デジタル配信のコスト構造:
  デジタル化費用 + プラットフォーム手数料（30-40%） → 低コスト → マージン15-20%

差分: 印刷・物流・返品コストの完全排除 → +13-16pt
```

## リターン分解

```
MOIC ~3x の分解:

① EBITDAの成長（1-2億 → 8-10億）       → マージン改善が主ドライバー
② マルチプルの変化（ほぼフラット）        → デジタル企業としての再評価
③ レバレッジ                               → 限定的
```

### 3xに留まった理由（10x案件にならなかった理由）
1. **COVID-19の影響**: 2020年のExit時期は不確実性が高かった
2. **売上トップラインの急拡大はなし**: DXは利益率改善が中心で、売上の爆発的成長ではなかった
3. **Exit先の選択肢**: Beagleeは戦略的買い手だが、オークション競争は限定的だった可能性

## 教訓: DX投資の成功パターン

### NSSKのプレイブック
1. **DX専門人材の外部採用**: 楽天から15名規模のチームをリクルート
2. **全IP資産のデジタル化**: 紙→クラウドへの完全移行
3. **NVP®の適用**: ガバナンス・コンプライアンス・管理会計の近代化
4. **販売チャネルの再構築**: デジタル配信プラットフォームとの取引関係構築

### 他の案件への適用可能性
- **条件**: 強力なIP/コンテンツ資産 + レガシーな配信モデル
- **適用業種**: 出版、音楽、教育コンテンツ、メディア
- **KPI**: デジタル売上比率、EBITDAマージン、顧客あたり収益

### CLAUDE.md反映候補
> - DX投資のリターンは「マージン改善」が主ドライバー。トップライン成長は必ずしも必要ではない
> - 低マージン企業の投資判断は、EBITDA倍率ではなく「IP/資産価値」と「DX後のポテンシャルEBITDA」で行う
> - DX人材は内部育成ではなく外部から一括採用する方が早い（ぶんか社: 楽天から15名チーム）
