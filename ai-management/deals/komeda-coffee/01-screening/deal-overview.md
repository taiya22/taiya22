# ディール概要: コメダ珈琲店

| **ブランド** | 珈琲所コメダ珈琲店 |

## 投資時点の事業概要（2008年）

| 項目 | 数値 |
|------|------|
| 店舗数 | 約400店舗 |
| FC比率 | 94%超 |
| 主要エリア | 中部・東海地方（売上の約70%） |
| 客単価 | 約800-1,000円 |
| Entry EV | 約150億円（推定、USD 146M） |

### ビジネスモデルの特徴
- **94%超がFC**: 圧倒的にアセットライトなモデル
- **営業利益率 ~30%**: FC手数料+食材供給による高利益率
- **名古屋の「喫茶文化」**: モーニングサービス（ドリンクに無料トースト付き）が看板
- **広い座席・長時間滞在OK**: スタバとは真逆の「ゆったり」コンセプト
- 競合: スターバックス、ドトール、星乃珈琲店

## 投資テーマ

### 1. 全国展開の加速
- 中部・東海に集中した400店舗 → 全国1,000店舗へ
- 関東（首都圏）・関西への本格進出が最大の成長ドライバー
- FCモデルのため、新規FCオーナーの獲得が鍵

### 2. 組織の専門経営化
- 創業者は「自分には大きな組織を作る力がない」と明言
- プロ経営者の招聘、組織インフラ（人事・IT・管理）の構築
- FC加盟店への支援体制強化

### 3. ブランド力の維持・強化
- 「名古屋の喫茶店文化」を全国に広める
- シロノワール等のアイコン商品のブランディング
- 過度な効率化によるブランド毀損を回避

## Go/No-Go 判定

**判定: Go**

1. 驚異的な利益率（~30%）のFCモデル
2. 中部以外への展開余地が膨大
3. 創業者の友好的な売却意向
4. 景気後退耐性（2008年リーマンショック直前だが、喫茶店は不況に強い）
5. FCモデルのため、成長に大きな設備投資が不要
