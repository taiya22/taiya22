# バリュエーション & リターン分析: コメダ珈琲

## Entry Valuation（2008年3月）

| 項目 | 数値 |
|------|------|
| Entry EV | 約150億円（USD ~146M） |
| AP持分 | ~78% |
| ポッカ（サッポロ子会社）共同投資 | ~12% |
| EBITDA（推定） | 20-25億円 |
| Entry EV/EBITDA | 6.0x - 7.5x（推定） |

### エントリー時の環境
- 2008年3月: リーマンショック半年前
- 金融危機を挟んだが、FC型ビジネスは安定CF → 影響限定的
- サッポロHD子会社のポッカが5.6億円を共同投資

---

## Exit Valuation（2013年1月）

| 項目 | 数値 |
|------|------|
| Exit先 | MBKパートナーズ |
| Exit方法 | GP-to-GPセカンダリー |
| Exit EV | 約430億円（USD ~430-480M） |
| Exit EV/EBITDA | 12-15x（推定） |
| **MOIC** | **~7x** |
| 保有期間 | 約5年 |

### ポッカの共同投資リターン
- ポッカの5.6億円 → 約40億円に成長
- ポッカ単体で ~7x、推定IRR ~50%

---

## バリューアップ実績

| 指標 | Entry（2008） | Exit（2013） | 成長 |
|------|-------------|-------------|------|
| 店舗数 | ~400 | ~500+ | +25% |
| 展開エリア | 中部中心 | 関東・関西進出 | 全国化進行 |
| EV | ~150億円 | ~430億円 | **2.9x** |

## リターン分解

```
MOIC ~7x の分解:

① 事業成長（店舗数+25%、既存店成長）    → ~1.5x
② 利益率の維持・向上（FCモデル高利益率）  → ~1.2x
③ マルチプル拡大（6-7x → 12-15x）        → ~2.0x
④ レバレッジ効果                            → ~1.9x
                                              --------
                                              合計: ~7x
```

### マルチプル拡大の要因
- 全国展開の「実行証明」により、成長プレミアムが付与
- MBKが「まだ500店舗 → 1,000店舗超への成長余地あり」と評価
- FCモデルの安定CFがPEバイヤーにとって魅力的

## その後のバリューチェーン

| 期間 | オーナー | 店舗数 | イベント |
|------|---------|--------|---------|
| 2008-2013 | AP | 400→500+ | 全国展開開始 |
| 2013-2016 | MBK | 500→700+ | 展開加速 |
| 2016年6月 | IPO | 700+ | 東証一部上場 |
| 2024年現在 | 上場 | 1,061+ | MBK ~5x リターンでExit |

**AP(7x) → MBK(5x) → IPO**: 3段階のバリュークリエーションが連鎖した稀有な事例。
合計で創業者売却時の150億円 → 上場時価総額 数千億円へ。

---

## 教訓

1. **FCモデルの威力**: 設備投資不要で成長できるモデルは、PE投資に最適
2. **リーマンショック耐性**: 不況下でも安定CF。逆にバリュエーションが抑えられた好エントリー
3. **セカンダリーExit**: GP-to-GPは「まだ成長余地がある」案件で有効。買い手PEにとっても魅力的
4. **創業者との信頼関係**: 友好的な事業承継が、円滑なPMIと経営移行を実現
