## バリュークリエーション・ブリッジ

```
Entry → 店舗拡大(+25%) → 利益率維持 → マルチプル拡大(2x) → レバレッジ → Exit
 1.0x →    +0.5x       →   +0.2x   →      +2.0x         →  +3.3x   → ~7.0x
```

## Exit プロセス

- PEセカンダリー市場で複数のグローバルPEファンドが関心
- MBKパートナーズが「日本のFC外食チェーンの成長ストーリー」を最も高く評価
- Private Equity International誌が「7x secondary sale」として報道
- MBKはその後IPO（2016年）で~5xリターンを実現

## 主な学び

### 投資プロセスの観点
1. **エントリータイミング**: リーマンショック直前の投資だが、FCモデルの安定性がダウンサイドプロテクション
2. **バリューアップの焦点**: 「店舗拡大」と「組織専門化」の2軸に集中
3. **Exit戦略の柔軟性**: IPOではなくセカンダリーを選択 → 確実なリターン確定

### ファンドへの貢献
- AP史上最大級のリターン案件の一つ
- 日本PE業界全体の「事業承継バイアウト」モデルの成功事例として広く認知
- 「名古屋の喫茶文化を全国へ」というストーリーは、メディアからも好意的に報道

### CLAUDE.md反映候補
> - FCモデル（フランチャイズ）はPE投資に最適: アセットライト・安定CF・設備投資不要
> - GP-to-GPセカンダリーExitは、成長途上の案件で有効な出口戦略
> - 事業承継案件では創業者との信頼関係がPMI成否を左右する
> - マルチプル拡大は「成長の実行証明」により実現される → 入口のマルチプルより、出口時の成長ストーリーの説得力が重要
