## 1. 会社概要と事業環境

### GINZA RASINとは

RASIN Co., Ltd.は、東京・銀座に本拠を置く高級中古時計の専門リテーラーである。ロレックス、パテック フィリップ等の高級ブランド時計を取り扱い、「GINZA RASIN」のブランド名で銀座エリアに3店舗を展開していた。ECチャネルも保有し、成長中であった。

**投資時点（2021年）の事業プロファイル:**

| 指標 | 数値 |
|------|------|
| 売上高 | 約100億円 |
| EBITDA | 約10億円 |
| EBITDAマージン | 10% |
| 店舗数 | 3店舗（銀座エリア） |
| 従業員数 | 約100名 |
| EC | あり（成長中） |

### 市場環境

中古高級時計市場は、以下の追い風を受けて世界的に拡大していた：

- **サステナビリティ意識の高まり**: 新品より中古品を選好する消費者トレンド
- **資産価値**: ロレックス等の高級時計が「資産」として認識される傾向
- **日本の優位性**: 保管状態の良い中古時計の供給源として世界的に高い評価
- **C2B取引の拡大余地**: 個人からの直接買取チャネルが未成熟

### 事業上の課題

RASINの最大のコスト課題は**仕入れ構造**にあった。仕入れの大部分をプロの卸市場（業者間オークション等）に依存しており、卸マージンが乗った高コスト構造が利益率を圧迫していた。

```
従来の仕入れフロー:
  時計オーナー → 買取業者 → 卸市場（業者オークション） → RASIN → 消費者
                  ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^
                  マージンが複数段階で積み上がる
```

## 2. 投資の意思決定

### ディールの経緯

創業者からの事業承継案件として、アント・キャピタルが株式の97.2%を取得（創業者3%残留）。カタライザー6号ファンド（+オフショアビークル MOMENTUM VI, L.P.）を通じて投資を実行した。

### エントリーバリュエーション

| 項目 | 数値 |
|------|------|
| Entry EV | 60億円 |
| Entry EV/EBITDA | **6.0x** |
| エクイティ | ~30億円 |
| デット | ~30億円 |
| エクイティ/デット比率 | 約50/50 |

6.0x EV/EBITDAは、リテールセクターとしては合理的な水準であり、DXによるアップサイドを織り込んでいないエントリーマルチプルであった。

### 投資テーマ: DXによる仕入れコスト革命

アント・キャピタルの投資仮説は明確であった：

> **「中古時計の最大のコストは仕入れである。プロの卸市場を経由する調達構造を、テクノロジーで個人からの直接買取（C2B）に転換すれば、1台あたりの仕入れコストを5-10%削減できる」**

この仮説を実現するための切り札が、自社開発プラットフォーム「**Owllar**」であった。

### Go/No-Go 判定の根拠

**Go判定** を下した5つの理由：

1. **明確なDX余地**: 仕入れのC2B転換という具体的なテクノロジー介入ポイント
2. **成長する市場**: 中古高級時計市場のグローバルな拡大トレンド
3. **合理的なエントリーマルチプル**: 6.0x EV/EBITDA（DXアップサイド未織込）
4. **事業承継案件の安定性**: 創業者が3%残留し、スムーズな経営移行
5. **自社DX実行能力**: アント社内にAI/DXチーム（4名）を保有し、外部委託なしで開発可能

## 3. バリューアップ施策

### Owllarプラットフォーム — 仕入れ構造の変革

アントの社内AI/DXチーム（4名）が企画・開発した「Owllar」は、以下の機能を持つモバイルプラットフォームである：

```
Owllar の3つのコア機能:

① 市場価格の可視化
   時計オーナーが保有する時計の市場需要・価格をリアルタイムで確認可能

② ダイレクト売却
   アプリから直接 RASIN に時計を売却可能（卸市場をバイパス）

③ AI価格最適化
   アント社内チームが開発したAIによる買取価格の最適化
```

**仕入れ構造の変化:**

```
Before（従来）:
  時計オーナー → 買取業者 → 卸市場 → RASIN
  コスト: 高い（複数段階のマージン）

After（Owllar導入後）:
  時計オーナー → [Owllar] → RASIN
  コスト: ▲5-10%/台の削減
```

### 売上成長戦略

Owllarによるコスト改善と並行して、以下の売上成長施策を実行：

- **オムニチャネル戦略**: 初回は店舗で購入体験 → 2回目以降はEC購入への誘導
- **EC比率の拡大**: デジタルマーケティング強化
- **売上倍増計画**: 3年で100億円 → 200億円

### バリューアップの実績

| 指標 | Entry（2021） | Exit（2024） | 成長率 |
|------|-------------|-------------|--------|
| 売上高 | 100億円 | 200億円 | **2.0x** |
| EBITDA | 10億円 | 22億円 | **2.2x** |
| EBITDAマージン | 10% | 11% | +1pt |

売上高が2.0x成長する中で、EBITDAが2.2x成長（マージンが+1pt改善）したことは、Owllarによる仕入れコスト削減が確実にP/Lに反映されたことを示している。

## 4. EXITプロセス

### 売却プロセスの設計

競争入札方式を採用。約**30社が関心表明**し、うち約10社がPEファンドであった。高い競争性が最終売却価格を押し上げた。

### 買い手: ヨンドシHD（4℃ブランド親会社）

ヨンドシHD（TSE: 8008）は、ジュエリーブランド「4℃」を展開する上場企業である。RASINの買収には以下の戦略的ロジックがあった：

| シナジー | 内容 |
|---------|------|
| クロスセル | 「ジュエリー × 高級時計」の商品ラインナップ拡充 |
| 顧客基盤 | RASINの富裕層顧客基盤へのアクセス |
| 市場トレンド | 成長する中古高級時計市場への参入 |

戦略的シナジーを持つ買い手が、財務バイヤー（PEファンド）を上回る価格を提示し、最終的にヨンドシHDが落札した。

### Exitバリュエーション

| 項目 | 数値 |
|------|------|
| Exit EV | 105億円 |
| Exit EV/EBITDA | **4.8x** |
| MOIC | **~3.5x** |
| 推定IRR | **~50%+** |

## 5. リターン分析

### MOIC ~3.5x の分解

```
                    ┌─────────────────────────────┐
                    │   Entry（1.0x）              │
                    │   ↓                          │
  Owllar開発        │   +0.5x（仕入れDX効果）      │
  (仕入れC2B化)     │   ↓                          │
                    │   +1.0x（売上2x成長）         │
  売上倍増          │   ↓                          │
                    │   +1.0x（EBITDA 2.2x成長）    │
  レバレッジ効果    │   ↓                          │
                    │   = ~3.5x（MOIC）             │
                    └─────────────────────────────┘
```

### 特筆すべき点: マルチプル縮小下でのリターン実現

| 項目 | 数値 | 備考 |
|------|------|------|
| Entry EV/EBITDA | 6.0x | |
| Exit EV/EBITDA | 4.8x | ▲20%縮小 |
| マルチプル変化 | **▲1.2x** | 高級品市場の一部減速を反映 |

マルチプルが20%縮小したにもかかわらず、MOIC 3.5x / IRR 50%+を達成した。これは**EBITDA成長（2.2x）とレバレッジ効果**がマルチプル縮小を十分にカバーしたことを意味する。

### 他のDX案件との比較

| 項目 | ぶんか社（NSSK） | RASIN（アント） |
|------|-----------------|----------------|
| DX対象 | コンテンツ配信（紙→デジタル） | 仕入れ（卸→C2B） |
| DX人材 | 外部一括採用（楽天から15名） | ファンド社内チーム（4名） |
| DX効果 | マージン +13-16pt | 仕入れコスト ▲5-10% |
| 保有期間 | 3.5年 | 3年 |
| MOIC | ~3x | ~3.5x |
| IRR | ~30-40% | ~50%+ |

## 6. 教訓と示唆（Lessons Learned）

### 教訓 1: DXは「バリューチェーンのどこに介入するか」が成否を分ける

RASINの成功は、DXの対象を「仕入れ」に絞り込んだことにある。ぶんか社が「コンテンツ配信」、RASINが「仕入れ調達」と、それぞれバリューチェーン上の最大のペインポイントを的確に特定し、そこにテクノロジーを投入した。

> **問い**: 対象会社のバリューチェーンで、最もテクノロジーで改善可能なコスト要因はどこか？

### 教訓 2: マルチプル拡大がなくてもリターンは出せる

本件はEntry 6.0x → Exit 4.8xとマルチプルが縮小した。しかし、EBITDA 2.2x成長とレバレッジ効果により、MOIC 3.5xを実現した。マルチプル拡大に依存しない投資モデルは、マクロ環境の変動に対して頑健である。

> **問い**: マルチプルが横ばい or 縮小した場合でも、EBITDA成長だけで目標リターンを達成できるか？

### 教訓 3: 社内DXチームはPEファンドの差別化要因になる

アントは社内に4名のAI/DXチームを保有し、Owllarを内製開発した。外部のコンサルやSIerに依存しないDX能力は、ディールソーシングの段階で「DXによるバリューアップの実現可能性」を説得力をもって示すことができる。

> **問い**: ファンドとして、どのようなDX/テクノロジー能力を内部に持つべきか？

### 教訓 4: 競争入札の設計が Exit バリューを最大化する

30社が関心を示した競争入札プロセスの中で、戦略的シナジーを持つヨンドシHDが最高値を提示した。**戦略的買い手がシナジーを見出せるポジショニング**を保有期間中に構築することが、Exit バリュー最大化の鍵である。

> **問い**: Exit時に戦略的買い手が最高値を出す構造を、投資後のバリューアップで作れるか？

### 教訓 5: 事業承継 + DX は「3年・3-4x」のリターンパターンを形成する

ぶんか社（3.5年・3x）とRASIN（3年・3.5x）の比較から、「レガシーな事業基盤 + DXインジェクション」の組み合わせは、短期間で3-4xのリターンを安定的に生み出すパターンとして認識できる。

## 7. ディスカッション設問

本ケースをもとに、以下の論点を検討されたい：

**Q1. 投資判断**
RASINの Entry EV/EBITDA 6.0x は適切な水準であったか。Owllarの成功確率をどう評価すべきだったか。

**Q2. DX施策の評価**
Owllarのような仕入れDXプラットフォームは、他のリテール業態にも応用可能か。適用条件は何か。

**Q3. Exit戦略**
3年での早期Exitは最適だったか。さらに保有を続けていれば、より高いMOICを実現できた可能性はあるか。マルチプル縮小トレンドを考慮した上で議論せよ。

**Q4. Taiga Capitalへの応用**
讃岐フーズ（冷凍うどん・惣菜メーカー）の案件に、RASINのDX戦略をどのように応用できるか。仕入れ・生産・流通のどこにテクノロジーを介入させるべきか。

**Q5. ファンド戦略**
アントのように社内DXチームを持つ戦略と、NSSKのように外部から一括採用する戦略、それぞれのメリット・デメリットを比較せよ。Taiga Capital Groupはどちらのアプローチを採用すべきか。
