# field/ — 現地記録（観測層 FIELD, v0.2）

CHISO.md 第I部 §6 の「4. 当たったか外れたかを記録して、地相に戻す」を受ける場所。

歩いた者にしか貯まらない差分——地形から演繹した仮説（ESTIMATE）と、現地で起きた事実——を
Markdown で蓄積し、地図上に観測層（FIELD）としてプロットする（v0.2で実装）。

## 記録テンプレート（案）

各訪問を1ファイル `field/YYYY-MM-DD_<place>.md` として置く。

```markdown
---
mesh: "54387300"           # 3次メッシュコード（任意）
lonlat: [138.41, 36.72]    # 実測地点
industry: onsen_ryokan     # 対象業種
visited: 2026-09-13
layer: FIELD
---

## 地形の推定は当たったか外れたか   ← 必須項目
当たり / 外れ / 部分的
（例：谷底の平坦地は推定どおり。ただし温泉の引湯距離が想定より長く、現況は…）

## 何を見たか（泊まった・食べた・歩いた・話した）
...

## 推定と事実の差分
- ESTIMATE では ○○ を示唆したが、現地では ××
- この差分から、規則 `rules/onsen_ryokan.yaml` の △△ を見直す余地

## 次にやること
...
```

## 原則の適用

- FIELD は独立した層。ESTIMATE / ACTUAL / LEGAL の値と掛け合わせて総合点にしない。
- 断定（有望・買うべき 等）は書かない。観測した事実と、推定との差分だけを残す。
- 記録は「判定の精度は差分の蓄積量に比例する」という前提のための一次資料。
