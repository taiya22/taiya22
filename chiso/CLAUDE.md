# CLAUDE.md

着手前に **CHISO.md を必ず読むこと。**

このプロジェクトの全ての判断基準・原則・要件・作業指針は `CHISO.md`（第I部 目的 ／ 第II部 要件定義 ／ 第III部 作業指針）にある。
実装で迷ったら CHISO.md 第III部「迷ったときの判断基準」に従う。

## 絶対に破ってはいけない4原則（要約 / 詳細は CHISO.md）

1. **三層を混ぜない** — 全指標は `ESTIMATE` / `ACTUAL` / `LEGAL` / `FIELD` のいずれかに属す。異なる層の値を掛け合わせて単一の数値にしない。
2. **合成した総合スコアを持たない** — 軸ごとに素の値を保持する。重み付けはビューアUIのみ。結果をデータに書き戻さない。
3. **すべての指標に `limitations` を持たせる** — 空にしない。書けないなら指標を作らない。
4. **断定を出力しない** — 「有望」「買うべき」「安全」「おすすめ」等の語を出力に使わない。

機械学習は使わない。判定は `rules/*.yaml` に人が書いた規則から演繹し、追跡可能にする。
生データ（`data/raw/`, `data/derived/`）はコミットしない。乱数を使わない（同じ入力→同じ出力）。
