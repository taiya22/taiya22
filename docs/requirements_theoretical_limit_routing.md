# 理論限界経路案内 — 要件定義書（簡易版）

最終更新: 2026-06-27 / バージョン: 0.1（ドラフト）

---

## 1. 背景・課題

Google Map をはじめとする既存の経路案内は「万人向けの安全側」に最適化されている。
乗り換えに余裕を持たせ、走る前提の経路は提示しない。そのため、以下のような
**時間がギリギリの意思決定**を支援してくれない。

- **終電ダッシュ**: 走れば終電に間に合うのか、間に合わないのか
- **朝の遅刻**: このまま電車で行くと何分遅刻するのか
- **間に合うか / タクシーか**: 電車とタクシーのどちらが速く・いくらかかるのか

求められているのは「最短経路の表示」ではなく、
**「最速経路 ＋ 間に合う確率 ＋ 代替手段（時間×金額）の比較」による意思決定支援**である。

---

## 2. 目的（このアプリが提供する価値）

1. **理論上の最速経路と所要時間**を提示する（走る・先回りなど攻めた前提を許容）
2. 目標時刻に対して**間に合う確率**を提示する
3. 間に合わない／際どい場合に**代替手段（タクシー・1駅先取り等）**を時間と金額で比較する

> ひとことで言うと「自己責任で攻めた最速を知りたい人のための意思決定ツール」。

---

## 3. スコープ

### 3.1 簡易版（MVP）でやること
- **終電ダッシュ判定**を中核機能とする（感情のピークが強く、競合が空いている）
- 現在地と目的駅から、最速経路・出発リミット・間に合う確率を算出
- 「電車 / タクシー / 徒歩+先回り」の簡易比較

### 3.2 MVPでやらないこと（将来拡張）
- 駅構内の詳細な歩行ナビ（ホーム間移動の精密計算）
- ユーザー個別の走力学習
- リアルタイム遅延の完全連携
- 多言語対応、決済連携

---

## 4. 想定ユーザー / 利用シーン

| ユーザー像 | 代表シーン | 求めるもの |
|---|---|---|
| 飲み会帰りの会社員 | 終電ダッシュ | 走れば間に合うかの即断 |
| 朝寝坊した通勤・通学者 | 遅刻回避 | 何分遅刻か／タクシー代替 |
| 商談・面接へ向かう人 | 際どい到着 | 電車 vs タクシーの損得 |

---

## 5. 機能要件

### F-1. 最速経路探索（必須）
- 出発地・目的地・目標時刻を入力すると、攻めた前提での最速経路を返す
- 「最短」ではなく「最速（理論限界寄り）」を採用

### F-2. 出発リミット逆算（必須）
- 終電・目標時刻から逆算し「あと何分以内に出発／ホーム到着が必要か」を提示
- 例: 「終電 23:47 発に乗るには、今から **12分30秒以内**に△△駅ホームへ」

### F-3. 間に合う確率（必須・簡易）
- 標準歩行速度／全力速度の前提から間に合う確率を概算で提示
- 例: 「全力で間に合う確率: 73% ／ 普通に歩くと: 間に合いません」
- ※初版は固定パラメータ（速度の前提値）で実装し、学習は将来対応

### F-4. 代替手段の比較（推奨）
- 電車 / タクシー / 徒歩＋1駅先取り を、到着時刻と概算金額で並べて提示
- 例: 「電車 9:03着（遅刻）／タクシー 8:52着・¥2,400／先回り 8:58着」

### F-5. 結果表示（必須）
- 「間に合う／際どい／間に合わない」を色・アイコンで一目で判別できる

---

## 6. 非機能要件

| 項目 | 要件 |
|---|---|
| 応答速度 | 検索から結果表示まで概ね3秒以内 |
| 対象端末 | スマートフォン（Web／将来ネイティブ） |
| 可用性 | 終電帯（深夜）に確実に動作すること |
| 免責 | 「自己責任での利用」を明示。安全を保証しない旨を表示 |

## 7. 外部データ / API（候補）

| 用途 | 候補 |
|---|---|
| 経路・所要時間 | Google Routes API / 駅すぱあと(ekispert) / NAVITIME |
| 駅構内データ | ekispert（ホーム間移動） |
| 運行・遅延情報 | 各鉄道事業者の運行情報 / 公共交通オープンデータ |
| タクシー料金 | 距離ベースの概算ロジック（初版は簡易計算） |

> MVPは「経路APIの最速モード ＋ 余裕時間の逆算 ＋ 速度前提の確率計算」だけで成立する。

## 9. 想定リスク・留意点

- **安全性**: 「走れ」と促すアプリのため、事故・転倒の自己責任を明示する必要がある
- **駅構内の精度**: ホーム間移動時間が最大の誤差要因。MVPでは固定マージンで吸収
- **走力の個人差**: 確率の前提が人により外れる。将来は本人実績から学習
- **遅延の扱い**: 終電は遅延で伸びることもあり、初版は定刻ベースで概算
