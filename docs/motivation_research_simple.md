## 第1章　そもそも「動機」って何？

### 動機 ＝ 人を動かすエンジン

動機とは、ある行動を「やろう」と思わせ、「続けよう」と思わせるもの。

たとえば:
- お腹が空いた → ご飯を食べに行く（生理的動機）
- テストでいい点を取りたい → 勉強する（達成の動機）
- 好きな人に認められたい → 頑張る（承認の動機）
- 世の中を変えたい → 起業する（目的の動機）

全部「動機」だ。でも種類が違う。
この「種類の違い」を整理することが、動機の研究の出発点になる。

### 動機は3つの層でできている

```
┌─────────────────────────────┐
│  第3層: 意味                │  ← 何のために生きるか
│  「自分を超えた目的」       │
├─────────────────────────────┤
│  第2層: 心理的な欲求        │  ← なぜ頑張るか
│  「自由・成長・仲間」       │
├─────────────────────────────┤
│  第1層: 生存                │  ← なぜ食べるか
│  「安全・お金・健康」       │
└─────────────────────────────┘
```

ポイント: **下の層が満たされないと、上の層に意識が向かない**。
お腹が空いて死にそうなとき、「自分を超えた目的」なんて考えられない。

でも逆に、**上の層が十分に強いと、下の層を無視できる人もいる**。
命がけで革命を起こす人、安定を捨てて起業する人。これは後で詳しく説明する。

## 第2章　世界の研究者たちが発見したこと

### 2.1 マズロー — 欲求のピラミッド（1943年）

心理学者マズローは、人間の欲求を5段階のピラミッドで整理した。

```
        /自己実現\        5. 自分らしく生きたい
       /  承認   \       4. 認められたい
      /  所属・愛  \      3. 仲間がほしい
     /   安全      \     2. 安心したい
    / 生理的欲求    \    1. 食べたい・寝たい
```

**分かったこと**: 人間の欲求には「順番」がある、という直観。
**問題点**: 実際には順番通りにいかない。認められたい（4）と仲間がほしい（3）を同時に追いかける人は普通にいる。

**ただし晩年に大事な修正をした**:
ピラミッドのてっぺんの上に「**自己超越**」を追加した。
自分のことだけじゃなく、**自分を超えた何かのために生きること**。
これが実は一番大事な概念になる。

### 2.2 ハーズバーグ — 「不満の解消」と「やる気」は別物（1959年）

ハーズバーグは画期的な発見をした:

> **給料を上げても「不満が減る」だけで「やる気は増えない」**。

| 不満を減らすもの（衛生要因） | やる気を生むもの（動機づけ要因） |
|---|---|
| 給料 | 達成感 |
| 職場環境 | 「よくやった」と認められること |
| 人間関係の安定 | 仕事そのものの面白さ |
| 雇用の安定 | 責任を任されること |
| | 成長の実感 |

つまり**お金はやる気の「土台」にはなるが、やる気の「燃料」にはならない**。

例えるなら:
- 給料 ＝ 車のガソリン。ないと走れない。でもガソリンを増やしても「運転が楽しくなる」わけじゃない。
- 仕事の面白さ ＝ 目的地の魅力。「あそこに行きたい！」と思うから、アクセルを踏む。

### 2.3 デシとライアン — 3つの心の栄養素（1985-2000年）

心理学の世界で**最も信頼されている**動機理論。
人間には3つの「心の栄養素」がある:

**1. 自律性（じりつせい）** — 自分で決められる感覚
> 「やらされてる」と感じた瞬間、やる気は消える。
> 「自分で選んだ」と感じると、同じ作業でもやる気が出る。

**2. 有能感（ゆうのうかん）** — 「できてる」という感覚
> 簡単すぎると退屈。難しすぎると挫折。
> 「ちょっと頑張ればできる」レベルが最も気持ちいい。

**3. 関係性（かんけいせい）** — 人とつながっている感覚
> 一人ぼっちでは、どんなに面白い仕事も長続きしない。
> 「この人たちと一緒にやりたい」と思える仲間がいること。

この3つが揃うと人は内側から燃える。
逆に、どれか一つでも奪われると、やる気が枯れる。

#### 最も危険な発見 — ご褒美がやる気を殺す

デシが1971年に発見した衝撃的な事実:

> **もともと好きでやっていたことに、お金のご褒美をあげると、**
> **お金をもらえなくなった途端に「もうやりたくない」と感じるようになる。**

これを「クラウディングアウト効果」と呼ぶ。

例:
- 子どもが絵を描くのが大好きだった
- 「上手に描けたら100円あげるよ」と言い始めた
- しばらくして100円をやめた
- → **もう絵を描かなくなった**

ご褒美が「好きだから描いてる」を「100円のために描いてる」に**すり替えてしまった**。

これは組織の報酬設計で極めて重要な教訓になる。

### 2.4 チクセントミハイ — フロー（没入）状態（1990年）

ゲームに夢中になって3時間が一瞬で過ぎた。
部活の試合中に「ゾーン」に入って体が勝手に動いた。

この**完全に没入している状態**を「フロー」と呼ぶ。

フローが起きる条件:

```
        高い
  不安   │          ★ フロー
         │        ╱
  挑戦の │      ╱
  レベル │    ╱
         │  ╱
         │╱  退屈
         └──────────────── 高い
               自分のスキル
```

- スキルが低いのに挑戦が高い → 不安（パニック）
- スキルが高いのに挑戦が低い → 退屈（だるい）
- **スキルと挑戦がちょうどバランス** → フロー（最高に集中）

加えて:
- 「何をすればいいか」が明確
- 「うまくいってるかどうか」がすぐ分かる
- 周りが気にならないほど集中している

**これが「やる気」の最高形態**。フローの中にいる人は、報酬がなくてもやり続ける。

### 2.5 マクレランド — 3つの欲求タイプ（1961年）

人には3つの欲求タイプがある:

| タイプ | 欲求 | こんな人 |
|---|---|---|
| 達成型 | 難しい目標を達成したい | 「自分との勝負」が好き。テストで1位を取りたい |
| 権力型 | 人に影響を与えたい | リーダーになりたい。組織を動かしたい |
| 親和型 | みんなと仲良くしたい | 調和を重視。チームワークが得意 |

面白い発見: 達成型の人は「成功確率50%」くらいの課題が一番好き。
簡単すぎると達成感がないし、無理すぎると挑戦する気にならない。
（フロー理論の「スキルと挑戦のバランス」と同じことを別の角度から言っている。）

権力型には2種類ある:
- **支配型**: 「俺の言うことを聞け」（恐怖で動かす）
- **威信型**: 「この人についていきたい」（尊敬で動かす）

後で出てくる「粋な経営者」は威信型。

### 2.6 アダムス — 人は「比較」する生き物（1963年）

> 自分の頑張り ÷ 自分の報酬 ≟ あの人の頑張り ÷ あの人の報酬

人は常に周りと比べている。
この比率が**不公平だと感じた瞬間**、やる気が急落する。

- 「俺の方が頑張ってるのに、あいつの方が給料高い」 → やる気崩壊
- 「みんな同じくらい頑張って、同じくらい報われてる」 → 信頼が生まれる

ただし、ここで大事なのは**結果の公平さより「プロセスの公平さ」**。
結果に差があっても、「決め方が透明で、みんなが納得できるプロセス」があれば、人は受け入れる。

### 2.7 グラント — 「人のため」×「自分のため」の掛け算（2007年）

アダム・グラントが発見した、動機の最強の組み合わせ:

| 組み合わせ | 結果 |
|---|---|
| 自分のため × 人のため | **最強のパフォーマンス** |
| 人のためだけ | 燃え尽きる（バーンアウト） |
| 自分のためだけ | 社会的インパクトが小さい |

つまり:
- 「好きだからやってる」だけじゃ弱い
- 「人のためにやってる」だけだと疲れる
- **「好きでやってて、しかもそれが人の役に立つ」が最強**

### 2.8 脳科学の発見 — ドーパミンは「予想外」に反応する

脳の中のドーパミン（やる気の物質）は、**報酬そのもの**ではなく、**予想と現実の差**に反応する。

```
予想より良い結果 → ドーパミンどっさり → 「もっとやろう！」
予想通りの結果   → ドーパミン変化なし → 「ふーん」
予想より悪い結果 → ドーパミン減少 → 「もうやめたい…」
```

つまり:
- **毎月もらえる定額の給料は、やる気を生まなくなる**。「当たり前」になるから。
- **予想外の「ありがとう」や新しい機会の方が、脳は喜ぶ**。

## 第3章　東洋の知恵

西洋の学者は「人はなぜ動くか」を科学的に分析した。
東洋の思想家は同じ問いに、まったく違う角度から答えを出した。

### 3.1 稲盛和夫 — 「動機善なりや、私心なかりしか」

京セラ・KDDIを作り、破綻したJALを立て直した稲盛和夫。
彼が大きな決断の前に必ず自分に問いかけた言葉:

> 「この判断の動機は善か？ 自分の利益だけで動いていないか？」

西洋の理論が「やる気をどう高めるか」を考えたのに対し、
稲盛は「**やる気の"質"がそもそも善いか**」を問うた。

### 3.2 禅 — 無心で没入する

禅の教えの核心は「無心」——考えることをやめて、今この瞬間に没入すること。

- **只管打坐（しかんたざ）**: 何の目的もなく、ただ座る
- **一行三昧（いちぎょうざんまい）**: 一つのことに完全に集中する

これはフロー理論の「自意識が消えて没入する」状態と驚くほど似ている。
チクセントミハイが実験室で発見したことを、禅僧は1000年前から実践していた。

### 3.3 武士道 — 名誉は「内側」にある

武士道の「名誉」は、他人に褒められることではない。
**自分が自分を恥じないこと**。

「武士道とは死ぬことと見つけたり」（葉隠）。
命よりも名誉を選ぶ。これは「安全の欲求」を完全に超えた動機。
マズローの「自己超越」の極限形態。

### 3.4 儒教 — 義で動くか、利で動くか

> 「君子は義に喩り、小人は利に喩る」（論語）
> 立派な人は正しさで動く。つまらない人は損得で動く。

これは「粋な経営者」と「そうでない経営者」の違いを2500年前に孔子が言い当てている。

### 3.5 仏教 — 菩薩の動機

仏教は「欲望は苦しみの原因だからなくせ」と教える。
でも例外がある。**菩薩（ぼさつ）の動機**:

> 「すべての生きとし生けるものが救われるために」動く

自分のためじゃない。全員のため。
これはグラントの「人のため × 自分のため」の、さらに先にある動機。

## 第5章　創業者の動機を解剖する

### 自分の動機を知ることが、なぜ大事か

「人を動かす仕組み」を作る人間は、まず**自分自身の動機を正確に理解**していなければならない。

自分の動機が分かっていないと:
- 自分に合わない仕事を選んでしまう
- 他人の動機を誤解する
- 組織の仕組みが自分の偏見に引っ張られる

### 3つのNoテスト

創業者の動機の根っこを炙り出すために、3つの問いを投げた。
答えはすべて「No」だった。

| 問い | 答え | 分かったこと |
|---|---|---|
| 誰にも知られなくても、深い仕事をやり続けたいか？ | No | 「見てもらえること」が必要 |
| 人の役に立っても、自分の手柄にならなくていいか？ | No | 「自分に帰属すること」が必要 |
| 尊敬されるけど、深い親しさはない関係で満足か？ | No | 尊敬はゴールじゃなく、親しくなるための入口 |

この3つのNoは重要な意味を持つ:
- 「好きだからやる」だけでは動かない → 内発的動機だけでは不十分
- 「人の役に立つ」だけでは動かない → 利他だけでは不十分
- 「尊敬される」だけでは動かない → 承認だけでは不十分

**どの理論も、単体では説明できない。全部が重なる交差点にしか真実はない。**

### 動機の回路図

3つのNoから浮かび上がった動機の回路:

```
  ① 独自の視点を持つ（Claim）
      │
      ▼
  ② その視点で現実を変える（Impact）
      │
      ▼
  ③ 変化が他者に観測される
      │
      ▼
  ④ 他者が自発的に敬意を与える（Prestige）
      │
      ▼
  ⑤ その敬意を足場に、深い関係に入る
      │
      ▼
  ⑥ 自分の存在意義が安定する
      │
      └──→ ①に戻る（次の独自視点へ）
```

この回路の特徴:
- **始まりは「独自の視点」**。他の人と同じ見方では始まらない
- **視点だけでは足りない**。現実を変えなければ意味がない
- **変えるだけでも足りない**。それが見てもらえなければ動機が回らない
- **見てもらうことがゴールじゃない**。見てもらうことで生まれる「深い関係」がゴール
- **終わりがない**。一つ達成したら、次の視点を求めて回り続ける

### 3つのSimple Rules（判断ルール）

この回路を、日常の判断に使える形にしたもの:

> **Prestige Rule**: 「これをやって、威信の証拠が残るか？」 — 残らないならやらない
>
> **Claim Rule**: 「一言で言える独自の仮説があるか？」 — ないならやらない
>
> **Impact Rule**: 「相手の行動が実際に変わるか？」 — 変わらないならやらない

この3つを全部クリアしたものだけに、時間とエネルギーを張る。
「やる理由」を考えるのではなく、**「やらない理由」をチェックする**方式。

### 理論との照合

この回路を、第2章の理論と突き合わせてみる:

| 理論 | 創業者の動機をどう説明するか | 説明できないこと |
|---|---|---|
| デシ&ライアン | 自律性・有能感・関係性の3つとも高い → 理想的 | 「どの方向に動くか」は説明しない |
| マクレランド | 達成型 × 威信型権力 × 選択的親和の珍しい組み合わせ | — |
| フロー理論 | Claim Rule ＝ 「明確な目標」、Impact Rule ＝ 「即時フィードバック」 | — |
| グラント | 利己（Prestige）× 利他（Impact）の統合 → 最強パターン | — |
| アダムス | 「金だけの人間が偉そうにしてる」への怒り ＝ 公正感の侵害 | — |
| 禅 | Claim Rule ＝ 雑念の排除。仮説が曖昧なら没入できない | — |
| 武士道 | Prestige Ruleの極限 ＝ 自分が自分を恥じない生き方 | — |

**結論**: どの理論も一面を正しく照らしているが、全体像は理論の重なりの中にしかない。

## 第6章　「粋な経営者」とは何か

### 「粋」の定義

「粋」という言葉は曖昧だ。そのままでは仕組みにできない。
だから「行動」で定義する。

| こういう場面で | 粋な経営者は | 粋じゃない経営者は |
|---|---|---|
| 勝ち方を選ぶとき | 周りも伸びる勝ちを選ぶ | 自分の取り分だけ最大化する |
| 厳しい局面 | 逃げずに自分で決める | 先延ばし、責任転嫁 |
| 情報と評価 | 透明にする | 身内びいき |
| 言葉と約束 | 雑に扱わない | その場しのぎ |
| 後継者 | 育てて権限を手放す | 自分がいないと回らない状態にする |

### 粋は「動機の成熟度」のこと

人は最初から粋ではない。動機は段階的に成熟する。

```
Stage 1: 生存     「まず食べていきたい」
    ↓
Stage 2: 証明     「自分は有能だと証明したい」
    ↓
Stage 3: 勝利     「とにかく勝ちたい。市場で一番になりたい」
    ↓
Stage 4: 独自性   「自分の視点で勝ちたい。他人のマネじゃなく」
    ↓
Stage 5: 影響     「人を動かしたい。相手が変わるのを見たい」
    ↓
Stage 6: 育成     「人を育てたい。自分より強い人を作りたい」
    ↓
Stage 7: 遺産     「自分がいなくても回る仕組みを残したい」
```

**「粋な経営者」とは、Stage 5以上にいる人のこと。**

- Stage 3（勝利）で止まっている人は、金のためなら粋じゃないことも平気でやる
- Stage 4（独自性）に到達した人には「粋の萌芽」がある
- Stage 5-6（影響・育成）に至った人が「粋な経営者」
- Stage 7（遺産）に到達できれば、創業者がいなくなっても組織は回り続ける

### 創業者の現在地

創業者はStage 5（影響）からStage 6（育成）への移行期にいる。

「関わった人のポテンシャルを引き出したい」→ Stage 5
「粋な経営者を育てる仕組みを作りたい」→ Stage 6
「自分の寿命を超えても回る機構を残したい」→ Stage 7への志向

Taiga Capital Groupの30兆円構想は、**Stage 7の制度化**そのもの。

## 第7章　仕組みをどう作るか — 7つの原則

動機の研究から導かれた、組織の仕組みを作るための7つの原則:

### 原則1: お金で「不満」は消せるが、「やる気」は買えない

> 給料は大事。でも給料を上げても「やる気」は上がらない。
> やる気は仕事そのものの設計から生まれる。

*（ハーズバーグの二要因理論）*

### 原則2: 自律性は「与える」のではなく「奪わない」

> 人間はもともと自分で動きたい生き物。
> 組織がやるべきは「自由を与える」ことじゃなく、「無駄なルールで自由を奪わない」こと。

*（デシ&ライアンの自己決定理論）*

### 原則3: 「自分のため」と「人のため」を対立させない

> 「自分が得する」ことと「人の役に立つ」ことが同時に起きる構造を作る。
> 利己を否定するんじゃなく、利己と利他が一致するポジションに人を配置する。

*（グラント × 稲盛和夫）*

### 原則4: 「ちょっと難しい」を常に提供する

> 簡単すぎると退屈で辞める。難しすぎると不安で潰れる。
> 今のスキルより「少しだけ上」の挑戦を、常に用意し続ける。

*（フロー理論 × マクレランドの達成動機）*

### 原則5: 結果の平等より、プロセスの公正

> 全員に同じ報酬を配る必要はない。
> でも「なぜあの人がこの報酬なのか」の決め方が透明で一貫していること。

*（アダムスの公正理論）*

### 原則6: 予測可能な報酬を超える

> 毎月同じ給料は「当たり前」になる。脳が反応しなくなる。
> 予想外の機会（新しい挑戦、信頼の証としての抜擢）が脳を再点火する。

*（ドーパミンの報酬予測誤差）*

### 原則7: 意味は「押し付ける」のではなく「見つけさせる」

> 「我が社のミッションはこれだ！」と叫ぶだけでは人は動かない。
> 一人ひとりが、自分の仕事の中に自分の意味を発見できる余白を残す。

*（禅の「無心」 × マズローの自己超越）*

## 第9章　結論 — 一言で言うと

### この研究で分かったこと（5つ）

**1. どの理論も一つでは足りない**
マズローだけでもダメ。フローだけでもダメ。全部が重なる交差点に答えがある。

**2. 「粋」は美意識ではなく、動機の成熟度**
Stage 5以上に到達した人間の自然な振る舞いが「粋」に見える。

**3. お金は動機の20%しかカバーしない**
残り80%は、仕事の面白さ、自由、成長、仲間、意味で決まる。

**4. 報酬は動機を殺しうる**
好きでやっていることに不適切な報酬をかぶせると、やる気そのものが壊れる。

**5. 東洋思想は西洋理論の限界を超える**
利己と利他は対立しない。模倣と独自性は矛盾しない。結果への執着を手放すとフローに入る。
