# 自己紹介の型

> 目的：入社初日〜1週目で「面を獲る」ための自己紹介フレームワーク

---

## 基本フレーム（30秒 / 1分 / 3分）

### 30秒版（エレベーターピッチ）

> 全体会や大人数の場面。名前と「引っかかり」を残すことに集中。

```
山脇大河です。慶應の修士で〇〇を研究していました。
趣味は［具体的で意外性のあるもの1つ］です。
よろしくお願いします。
```

**ポイント：**
- 「引っかかり」＝後で話しかけてもらえるフック。趣味・出身・研究テーマなど意外性のあるもの1つに絞る
- 全部を伝えようとしない。30秒で覚えてもらえるのは1つだけ

---

### 1分版（チーム・部門の自己紹介）

> 配属先や少人数グループでの場面。「何ができそうか」の期待値を作る。

```
山脇大河です。慶應の修士課程で〇〇を研究していました。

学生時代は［プロジェクト/活動の名前］をやっていて、
そこで［具体的なスキル・経験：例「チームで事業計画を作って投資家にピッチする」］
ということをしていました。

まだ何もわからない新人ですが、
［自分が貢献できそうなこと1つ：例「AIツールの活用」「資料作り」］
は得意なので、何かあればぜひ声をかけてください。
よろしくお願いします。
```

**ポイント：**
- 「何かあれば声をかけてください」＝ Giverの入口を作る
- 謙虚さ（新人の自覚）＋ 1つだけ「使える」を見せる

---

### 3分版（飲み会・懇親会・1on1）

> カジュアルな場面。人間性を伝えて距離を縮める。

```
1. 名前・出身・大学院でやっていたこと（30秒）
2. なぜデロイトに来たか（30秒）
   → 「M&Aアドバイザリーの現場で、企業の意思決定を間近で見たかった」等
     Whyから入る。志望動機の丸暗記ではなく、自分の言葉で
3. 学生時代に一番面白かったこと（1分）
   → 具体的なエピソード1つ。修羅場系が盛り上がる
4. 趣味・最近ハマっていること（30秒）
   → 相手との共通点を探る入口になるもの
5. 「〇〇さんは何がきっかけでデロイトに？」（30秒）
   → 自分の話で終わらせない。相手に質問を返す
```

**ポイント：**
- 自己紹介は「自分を語る場」ではなく「関係を始める場」
- 最後に必ず相手への質問で締める（インタビュー力を活かす）
- Considerateness：相手が話しやすい空気を作る

---

## 場面別の使い分け

| 場面 | 版 | 意識すること |
|------|-----|-------------|
| 全体研修の初日 | 30秒 | フック1つ。覚えてもらう |
| 部門・チーム配属 | 1分 | 貢献できること1つ見せる |
| 懇親会・ランチ | 3分 | 相手への質問で締める |
| 先輩との1on1 | 3分 | 「教えてほしい」姿勢を前面に |
| 他部門の人と偶然会った | 30秒 | 名前と部門だけでもOK。次に繋げる |

---

## 準備しておくもの

- [ ] 30秒版の「引っかかり」ネタを3つ候補出し → 1つに絞る
- [ ] 「なぜデロイトに来たか」を自分の言葉で30秒で言えるようにする
- [ ] 学生時代のエピソードを1つ、起承転結で話せるように整理
- [ ] 相手に返す質問のストックを5つ用意

---

## 注意（自分の弱みへの対策）

- **堅くなりすぎない** → 完璧に話そうとしない。笑顔と声のトーンの方が大事
- **一方的に話しすぎない** → 自己紹介は1分以内。残りは相手の話を聞く
- **「すごい人」に見せようとしない** → 新人は「素直さ」と「元気さ」が最強の武器
