## 偶然遭遇

- **提唱者：** 楠木建（一橋ビジネススクール特任教授）
- **原典：** 楠木建オフィシャルブログ「祝還暦」（2017/4/7）── https://ameblo.jp/groovyken/entry-12263349952.html
  - 「僕はこの『偶然遭遇』というものをヒジョーに重視している」
  - デザイナー小野光治さんとの3年間にわたる偶然遭遇（新丸ビル駐車場、新幹線、銀座の駐車場）を例に語っている
- **文脈：** カフェで別ゼミの子と「なぜかバッタリ遭遇する」現象から想起（2026/3/23）
- **概念の要旨：** 好きなことを追求し、自分のコンセプトに沿って動いていると、偶然の出会いが必然的に起こるようになる。キャリアや人生の重要な転機は、計画ではなく「偶然の遭遇」から生まれることが多い。
- **関連する楠木建の主張：**
  - 『好きなようにしてください』第20章「キャリアは計画できない」
  - キャリアの詳細計画より「キャリアコンセプト」を持つことが重要
  - 好き嫌いに忠実に動くことで、良い偶然を引き寄せる
- **関連理論：**
  - **計画的偶発性理論（Planned Happenstance Theory）** ── クランボルツ（スタンフォード大学）
  - キャリアの8割は偶発的な要素で決まる
  - 良い偶然を引き寄せる5つの行動特性：好奇心・持続性・柔軟性・楽観性・冒険心
- **Taigaとの接続：**
  - Value の Curiosity（好奇心に従う）と直結
  - Experiment（とにかく実験）の姿勢が偶然遭遇を増やす
  - 「面を獲る」＝偶然遭遇の確率を上げる行動
