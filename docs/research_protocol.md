# 研究プロトコル：Prestige型動機と Post-Financial Freedom Motivation の実証研究

*Taiga Capital Group — Research Division*
*Date: March 2026*
*Version: 1.0*
*Status: Draft Protocol*

## 概要

本文書は、research_gaps.md で特定された7つの研究ギャップのうち、Phase 1 として即座に着手可能な **RQ2（Prestige vs Dominance の分岐条件）** と **RQ6（Post-Financial Freedom Motivation）** を統合した実証研究のプロトコルである。

### メインクレーム（1文）

> **経済的自由を達成した経営者において、初期キャリアでの「他者の成長への貢献体験」の有無が、権力動機のPrestige型（自発的追随）への発達を予測し、その発達がPost-Financial Freedom期の持続的パフォーマンスを説明する。**

---

## 1. 研究の背景と根拠

### 1.1 知的空間における位置づけ

| 確立された知見（Known） | 未解明の問題（Unknown） |
|---|---|
| 権力動機（nPow）は経営者の成功を予測する（McClelland & Boyatzis, 1982） | Prestige型 vs Dominance型への分岐条件が組織文脈で未研究 |
| 進化心理学でPrestige/Dominance区分は確立済（Henrich & Gil-White, 2001） | この区分が経営行動・組織成果に接続されていない |
| 起業家の動機構造は概観されている（Shane et al., 2003; Cardon et al., 2009） | 経済的自由達成後の動機再編を追跡した研究がない |
| 内発的動機と向社会的動機の統合が最高の持続性を予測する（Grant, 2008） | この統合がどのキャリア経験によって促進されるか未解明 |

### 1.2 二次メタ分析との接続

本プロトコルは、同時に作成された二次メタ分析（meta_analysis_paper.docx）の知見を前提としている。メタ分析の中心的知見は「タスクの認知的複雑性が高いほど、内発的動機がパフォーマンスの支配的予測因子となり、外発的誘因の効果は減少する」というクロスオーバーパターンである。

経営者の仕事は最大複雑性の知的労働であり、メタ分析に従えば**内発的動機が支配的レバー**となる。したがって、経営者の内発的動機を支えるPrestige型の権力動機構造を理解することは、単なる学術的関心ではなく、Taigaの報酬・評価・選抜制度の**理論的必然**である。

### 1.3 なぜこの2つのRQを統合するか

RQ2（Prestige vs Dominance）とRQ6（Post-Financial Freedom Motivation）は、同一の研究対象（経済的自由を達成した経営者層）に対して、**動機の質**（Prestige型か否か）と**動機の源泉**（経済的必要性が消えた後に何が駆動するか）を同時に調査できる。統合することで：

1. **対象者の重複** — 同一インタビュー・サーベイで両方のデータを収集可能
2. **理論的接続** — Prestige型動機への発達が、Post-FF期の持続的動機の前提条件である可能性
3. **実務的有用性** — Taigaの経営者選抜・育成において、両方の知見が即座に活用可能

## 2. リサーチクエスチョン

### 主RQ

> 経済的自由を達成した経営者の権力動機は、どのようなキャリア経験を経てPrestige型に発達するか、そしてPrestige型への発達はPost-Financial Freedom期の持続的パフォーマンスをどの程度予測するか？

### 下位RQ

| ID | 下位RQ | 対応Gap |
|---|---|---|
| SRQ1 | 経営者の権力動機をPrestige型とDominance型に弁別する行動指標は何か？ | Gap 2 |
| SRQ2 | どのようなキャリア経験（メンタリング・他者育成・失敗・海外経験等）がPrestige型への分岐を促進するか？ | Gap 2 |
| SRQ3 | 経済的自由達成後、動機構造はどのように再編されるか（nAch, nPow, nAff, 向社会的動機, 自己超越の変化）？ | Gap 6 |
| SRQ4 | Prestige型動機は、Post-FF期の持続的パフォーマンス（事業継続年数、組織成長、後継者育成数）を予測するか？ | Gap 2 × 6 |

## 3. 研究デザイン

### 3.1 混合研究法（Sequential Explanatory Design）

```
Phase A: 質的研究（探索的）
    深層インタビュー → 仮説生成 → 行動指標の開発
        │
        ▼
Phase B: 量的研究（検証的）
    サーベイ調査 → 仮説検証 → Prestige/Dominance尺度の妥当性検証
        │
        ▼
Phase C: 縦断的追跡（確認的）
    12ヶ月フォローアップ → 予測妥当性の検証
```

### 3.2 Phase A — 質的研究

#### 対象者

| 条件 | 基準 |
|---|---|
| 経済的自由の達成 | 個人資産 > 生涯支出見込の5倍以上（自己報告＋客観指標） |
| 経営経験 | CEO/代表取締役として3年以上の経験 |
| 継続的活動 | 経済的自由達成後も事業経営・投資に積極的に関与 |
| サンプルサイズ | n = 20–30（理論的飽和を判断基準） |

#### リクルートメント戦略

1. **Taiga Capital ネットワーク内**（n = 8–12）: ポートフォリオ企業経営者、LP、アドバイザー
2. **外部ネットワーク**（n = 8–12）: PEファンドGP、連続起業家、ファミリーオフィス運営者
3. **対照群**（n = 4–6）: 経済的自由達成後に活動を停止/縮小した元経営者

#### インタビュー・プロトコル

**形式**: 半構造化深層インタビュー（90–120分）

**セクション1: キャリア史と動機の変遷**（30分）
1. 最初のキャリア選択の動機は何だったか
2. 最も困難だった時期に何が自分を動かしたか
3. 「もう経済的には十分だ」と感じた最初の瞬間を覚えているか
4. その瞬間の前後で、仕事への向き合い方はどう変わったか

**セクション2: 権力動機の探索**（30分）
5. 他者に影響を与えたいと思うか。それはどのような形の影響か
6. 部下や同僚があなたに「従う」理由は何だと思うか
7. 自分の判断が覆されたとき、どう感じるか
8. 後輩・部下の成長を見たとき、どう感じるか。具体的なエピソードは
9. 自分より優れた人材が現れたとき、脅威を感じるか

**セクション3: Post-Financial Freedom の動機源泉**（30分）
10. 今、朝起きて仕事に向かう動機は何か
11. 「もうやめてもいい」のにやめない理由は何か
12. 10年後、自分のレガシーとして何が残っていてほしいか
13. 報酬が完全にゼロだとしたら、今の活動を続けるか
14. 仕事以外で最も充実感を感じる瞬間は何か

#### コーディング手法

**1次コーディング**: オープンコーディング（grounded theory approach）
**2次コーディング**: 理論的コーディング — 以下のa prioriカテゴリと創発カテゴリを統合

| a priori カテゴリ | 理論的根拠 | コーディング例 |
|---|---|---|
| Prestige型権力動機 | Henrich & Gil-White (2001) | 「実力で認められたい」「育てた人が成功すると嬉しい」 |
| Dominance型権力動機 | Henrich & Gil-White (2001) | 「最終決定権は譲れない」「部下は命令に従うべき」 |
| 内発的動機の持続 | SDT (Ryan & Deci, 2000) | 「仕事自体が面白い」「新しい問題を解くのが好き」 |
| 向社会的動機 | Grant (2008) | 「人のポテンシャルを引き出したい」「社会に還元したい」 |
| 自己超越 | Maslow (1969) | 「自分を超えた何かを残したい」「個人の成功は興味がない」 |
| アイデンティティ駆動 | Cardon et al. (2009) | 「経営者であることが自分のアイデンティティ」 |
| 動機の空白/喪失 | 新規カテゴリ | 「正直、何のためにやっているか分からないときがある」 |

#### 分析手法

- **テーマ分析**（Braun & Clarke, 2006）: 主題の抽出と構造化
- **ケース比較分析**: Prestige型 vs Dominance型、活動継続群 vs 停止群の比較
- **メンバーチェック**: 分析結果を対象者に還元し、解釈の妥当性を確認

### 3.3 Phase B — 量的研究

#### Prestige/Dominance 権力動機尺度（新規開発）

Phase Aの質的知見に基づき、以下の構造の尺度を開発する。

**Prestige型権力動機（仮説的項目例）**:
1. 自分の専門性を通じて他者に影響を与えたい
2. 部下の成長を見ることが最大の報酬だ
3. 周囲が自発的に自分についてくることを重視する
4. 知識や経験を惜しみなく共有する方だ
5. 自分より優れた人材を積極的に採用したい
6. 自分がいなくても組織が回ることを理想とする

**Dominance型権力動機（仮説的項目例）**:
1. 重要な意思決定は自分が最終決定すべきだ
2. 組織内で自分の地位が脅かされることに敏感だ
3. 部下には明確な指示を与え、実行を求めるべきだ
4. 自分の判断が覆されると不快に感じる
5. 組織内の情報は自分が管理すべきだ
6. 競争に勝つことが経営の本質だ

#### 既存尺度の併用

| 尺度 | 測定概念 | 出典 |
|---|---|---|
| Work Extrinsic and Intrinsic Motivation Scale (WEIMS) | SDT動機連続体 | Tremblay et al. (2009) |
| Prosocial Motivation Scale | 向社会的動機 | Grant (2008) |
| Balanced Inventory of Desirable Responding (BIDR) | 社会的望ましさバイアス統制 | Paulhus (1991) |
| Self-Transcendence Scale | 自己超越 | Cloninger et al. (1994) |
| Entrepreneurial Passion Scale | 起業家の情熱 | Cardon et al. (2013) |

#### サンプルサイズの算出

- **効果量の想定**: Cohen's d = 0.50（Prestige群 vs Dominance群のパフォーマンス差、中程度の効果）
- **α = .05, 1-β = .80**
- **必要サンプルサイズ**: n = 128（各群64名）
- **脱落率 20%想定**: 初期リクルート n = 160

#### 分析計画

1. **探索的因子分析（EFA）**: Prestige/Dominance尺度の因子構造確認
2. **確認的因子分析（CFA）**: 2因子モデルの適合度検証
3. **弁別妥当性**: Prestige/Dominance尺度とSDT尺度（WEIMS）との相関パターン
4. **回帰分析**: Prestige型動機 → Post-FF パフォーマンス指標（事業継続、組織成長、後継者育成）
5. **媒介分析**: キャリア経験（他者育成経験量） → Prestige型動機 → パフォーマンス

### 3.4 Phase C — 12ヶ月縦断追跡

Phase Bの参加者のうち同意を得た者（目標 n = 100）に対し、12ヶ月後にフォローアップ測定。

**測定内容**:
- Prestige/Dominance尺度（再測定 → test-retest信頼性）
- 客観的パフォーマンス指標（売上成長率、従業員数変化、新規事業開始数）
- 後継者育成指標（育成した幹部数、権限委譲の程度）
- 組織文化指標（従業員サーベイ：自律的動機の平均スコア）

## 4. 変数の操作定義

### 4.1 独立変数

| 変数 | 操作定義 | 測定方法 |
|---|---|---|
| 権力動機タイプ | Prestige型 vs Dominance型の連続体 | 新規開発尺度（Phase B） |
| 「他者の成長への貢献体験」 | キャリアにおいて他者のメンタリング・育成に費やした時間と質 | インタビュー（Phase A） + サーベイ項目（Phase B） |
| 経済的自由の達成時期 | 個人資産 > 生涯支出見込5倍を達成した年齢 | 自己報告 + 客観指標 |

### 4.2 従属変数

| 変数 | 操作定義 | 測定方法 |
|---|---|---|
| Post-FF持続的パフォーマンス | 経済的自由達成後の事業関与度と成果 | 複合指標（事業継続年数 × 組織成長率 × 後継者育成数） |
| 組織への動機文化伝播 | 経営者の動機構造と従業員の動機構造の相関 | 経営者と従業員のSDT尺度スコアの組織内相関 |

### 4.3 媒介変数

| 変数 | 操作定義 | 測定方法 |
|---|---|---|
| 内発×利他の統合度 | 内発的動機スコア × 向社会的動機スコアの交互作用項 | WEIMS × Prosocial Motivation Scale |

### 4.4 統制変数

| 変数 | 根拠 |
|---|---|
| 年齢 | 発達段階の交絡 |
| 業種 | 業種による権力動機の文脈依存性 |
| 教育歴 | 認知的複雑性の代理指標 |
| 経済的自由の水準（資産額） | 経済的制約の残存度 |
| 社会的望ましさバイアス | BIDRスコアで統制 |

## 5. 倫理的配慮

1. **機密性**: 対象者は富裕層であり、資産情報・動機構造は極めてセンシティブ。全データは匿名化し、個人特定可能な情報は別サーバーに暗号化保管
2. **利益相反**: Taiga Capitalのネットワーク内からリクルートするため、参加の任意性を明示。Taigaとの取引関係に一切影響しないことを書面で保証
3. **インタビューの心理的負荷**: キャリアの困難・動機の空白に触れる可能性。臨床心理士によるデブリーフィングを準備
4. **研究倫理審査**: 提携大学のIRB（機関研究倫理委員会）での承認を取得

## 7. 期待される成果と Taiga への含意

### 7.1 学術的貢献

1. **Prestige/Dominance権力動機尺度**: 組織文脈で使用可能な初の弁別尺度
