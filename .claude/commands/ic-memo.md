# ICメモ — 投資委員会メモのドラフト生成

指定案件のICメモドラフトを作成します。

## 引数
- $ARGUMENTS: 案件名

## やること

1. 指定案件の `deals/{案件名}/` 配下から以下を収集:
   - `01-screening/` のスクリーニングメモ
   - `02-due-diligence/` のDD結果
   - `03-valuation/` のバリュエーション結果
2. 以下の構成でICメモドラフトを生成:

```
1. エグゼクティブサマリ（1ページ）
2. 投資テーマ・投資ハイライト
3. 会社概要
   - 事業概要、沿革、組織
   - 市場環境、競合ポジション
4. 財務分析
   - 過去実績サマリ
   - 正常EBITDA（DD調整後）
   - 事業計画の妥当性評価
5. バリュエーション
   - DCF / Comps / 先行取引の結果
   - フットボールフィールド
6. ディールストラクチャー
   - 取得価格、資金調達、条件
7. リスク分析
   - リスクマトリクス（発生可能性 × 影響度）
   - リスク軽減策
8. リターン分析
   - Base / Bull / Bear シナリオ別 IRR・MOIC
9. 結論・推奨
```

3. 結果を `deals/{案件名}/04-ic-memo/` と `ai-management/output/reports/` に保存

## 注意
- 投資判断の結論部分は「推奨案」として提示し、最終判断は投資委員会に委ねる旨を明記
