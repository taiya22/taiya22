# DDチェックリスト — デューデリジェンスチェックリスト生成

指定案件のDDチェックリストを生成・管理します。

## 引数
- $ARGUMENTS: 案件名、DDタイプ（financial / legal / tax / operational / all）

## やること

1. 指定案件の `deals/{案件名}/02-due-diligence/` を確認（なければ作成）
2. DDタイプに応じたチェックリストを生成:

### Financial DD
- [ ] 過去3-5年の監査済み財務諸表の入手
- [ ] 月次管理会計データの入手
- [ ] 試算表・総勘定元帳の入手
- [ ] EBITDA Bridge（正常収益力分析）
- [ ] 運転資本分析（季節性、トレンド）
- [ ] Net Debt / Debt-like items の特定
- [ ] 収益品質分析（顧客集中度、リカーリング比率）
- [ ] Capex分析（維持Capex vs 成長Capex）
- [ ] オフバランス項目の確認
- [ ] マネジメントQ&Aリスト作成

### Legal DD
- [ ] 定款・登記簿謄本
- [ ] 株主名簿・株主間契約
- [ ] 重要契約（Change of Control条項確認）
- [ ] 訴訟・紛争リスト
- [ ] 許認可・ライセンスの確認
- [ ] 知的財産権の確認
- [ ] コンプライアンス体制

### Tax DD
- [ ] 過去の税務申告書
- [ ] 税務調査の履歴
- [ ] 繰越欠損金・税務上の資産
- [ ] 移転価格リスク
- [ ] ストラクチャー関連の税務リスク

### Operational DD
- [ ] 組織図・人員構成
- [ ] 主要顧客・仕入先の分析
- [ ] IT システム・インフラ
- [ ] 業務プロセスの効率性
- [ ] ESG・環境リスク

3. チェックリストを `deals/{案件名}/02-due-diligence/` に保存
