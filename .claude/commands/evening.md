# 振り返り — 今日の業務からの学びのまとめ

1日の終わりに、今日の業務内容を振り返り、学び・気づきを構造化して記録します。

## やること

1. **今日のセッション履歴**を確認し、実施した作業を棚卸し
2. **work-log/** の今日のログを確認（あれば参照）
3. 以下の観点で学びを抽出:
   - **うまくいったこと**: 効率的だったプロセス、良い判断
   - **改善点**: 手戻り、判断ミス、非効率だったプロセス
   - **新しい知見**: 初めて遭遇したケース、業界知識、技術的発見
   - **CLAUDE.mdへの反映候補**: 今日の経験からルール化すべきこと
4. 学びログを `ai-management/work-log/learnings/YYYY-MM-DD.md` に保存
5. CLAUDE.mdへの反映候補がある場合、具体的な追記案を提示（反映はユーザー確認後）

## 出力形式

```markdown
# 業務振り返り YYYY/MM/DD

## 今日の実施事項
- ...

## 学び・気づき

### うまくいったこと
- ...

### 改善点
- ...

### 新しい知見
- **案件**: {案件名}
- **カテゴリ**: バリュエーション / DD / ストラクチャー / 会計 / 業界知識 / その他
- **内容**: ...
- **今後の適用場面**: ...

## CLAUDE.md 反映候補
> 以下のルールを追加することを推奨します:
> - 「...」

## 明日への申し送り
- [ ] ...
```
