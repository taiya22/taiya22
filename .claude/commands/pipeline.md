# パイプライン — ディールパイプライン管理

deals/ 配下のディールパイプライン状況を確認・更新します。

## やること

1. **deals/** 配下の全案件フォルダをスキャン
2. 各案件のフェーズ（01-screening 〜 06-monitoring）を判定
3. パイプライン一覧をテーブル形式で表示
4. 引数が指定された場合、該当案件の詳細を表示

## 出力形式

```
===== ディールパイプライン =====

| # | 案件名 | セクター | フェーズ | ステータス | 最終更新 |
|---|--------|---------|---------|-----------|---------|
| 1 | ...    | ...     | DD      | 進行中     | ...     |

合計: X件（スクリーニング: X / DD: X / バリュエーション: X / IC: X / クロージング: X / モニタリング: X）
```
