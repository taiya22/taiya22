# バリュエーション — バリュエーション分析の起動

バリュエーション分析のセットアップと実行を支援します。

## 引数
- $ARGUMENTS: 案件名、または分析手法の指定（dcf / comps / lbo / precedents）

## やること

1. 指定された案件の `03-valuation/` フォルダを確認（なければ作成）
2. 指定された手法に応じてテンプレートを準備:
   - **DCF**: 前提条件（売上成長率、EBITDAマージン、WACC、Terminal Growth Rate）の入力を促す
   - **Comps**: 類似企業リストの作成、マルチプル（EV/EBITDA, EV/Revenue, P/E）のテーブル生成
   - **LBO**: エントリーマルチプル、レバレッジ、Exit想定の入力を促す
   - **Precedents**: 先行取引の検索条件を確認し、テーブル生成
3. 感度分析を実行（割引率 ±0.5%、成長率 ±0.5%）
4. バリュエーションサマリ（フットボールフィールド形式）を生成
5. 結果を `ai-management/output/valuations/` に保存

## 確認事項
- バリュエーション前提条件は必ずユーザーに確認してから確定すること
- 割引率・成長率・マルチプルの根拠を明示すること
