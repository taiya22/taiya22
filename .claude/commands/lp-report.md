# LPレポート — LP向けパフォーマンス指標の算出

ファンドのパフォーマンス指標を計算し、LPレポート用のサマリを生成します。

## やること

1. **fund/performance/** からキャッシュフローデータを読み込み
2. 以下の指標を算出:
   - **Gross IRR** / **Net IRR**（XIRR、日付ベース）
   - **MOIC**（総価値 ÷ 投資元本）
   - **DPI**（分配累計 ÷ 払込累計）
   - **RVPI**（残存価値 ÷ 払込累計）
   - **TVPI**（DPI + RVPI）
3. Gross → Net フィーブリッジを作成（管理報酬、キャリー控除）
4. ポートフォリオ各社の個別パフォーマンスサマリを生成
5. ヴィンテージイヤー比較（該当データがあれば）
6. 結果を `ai-management/output/reports/` と `fund/reporting/` に保存

## 出力形式

```
===== ファンドパフォーマンスサマリ =====
基準日: YYYY/MM/DD

■ ファンド全体
| 指標       | Gross    | Net      |
|-----------|----------|----------|
| IRR       | XX.X%    | XX.X%    |
| MOIC      | X.Xx     | X.Xx     |
| DPI       | X.Xx     | X.Xx     |
| RVPI      | X.Xx     | X.Xx     |
| TVPI      | X.Xx     | X.Xx     |

■ フィーブリッジ
Gross Return → 管理報酬 → キャリー → Net Return

■ ポートフォリオ個社別
| 投資先 | 投資額 | 現在価値 | MOIC | IRR | ステータス |
|-------|-------|---------|------|-----|----------|
```

## 注意
- IRRの計算結果は必ず妥当性を確認すること（複数解の可能性）
- 未実現分の公正価値は前提条件を明記すること
