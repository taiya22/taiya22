# EBITDA Bridge — 調整後EBITDA分析

報告EBITDAから調整後EBITDAへのブリッジを作成します。

## 引数
- $ARGUMENTS: 案件名、または財務データファイルのパス

## やること

1. 対象の財務データを読み込み
2. 以下の調整項目を特定・分類:

### 調整カテゴリ
- **非経常収益**: 資産売却益、保険収入、補助金（一時的なもの）
- **非経常費用**: 訴訟和解金、リストラ費用、退職金（特別）、災害損失
- **オーナー関連**: オーナー報酬の正常化、関連当事者取引、個人的経費
- **会計方針**: 減価償却方法の差異、引当金の過不足
- **ランレート調整**: 期中の価格改定、新規顧客・喪失顧客、コスト削減施策

3. ブリッジテーブルを生成:

```
===== EBITDA Bridge =====

| 項目                    | 金額 (M¥) | 備考           |
|------------------------|----------|---------------|
| 報告EBITDA              | XXX      |               |
| (+) 非経常費用           | XX       | 訴訟和解金 等   |
| (-) 非経常収益           | (XX)     | 資産売却益 等   |
| (+) オーナー報酬正常化    | XX       |               |
| (+/-) ランレート調整      | XX       |               |
| = 調整後EBITDA           | XXX      |               |
| 調整後EBITDAマージン      | XX.X%    |               |
```

4. 結果を `ai-management/output/analysis/` に保存

## 注意
- 各調整項目には根拠・出典を付記すること
- 判断に迷う調整項目は必ずユーザーに確認すること
