# 業務ログ — 作業内容の記録

今日の作業内容を業務ログとして記録します。

## 引数
- $ARGUMENTS: 記録したい内容（省略時は今日の作業を自動サマリ）

## やること

1. 今日の日付で `ai-management/work-log/YYYY-MM-DD.md` を作成（既存なら追記）
2. 引数が指定された場合、その内容を記録
3. 引数が省略された場合、今日のセッションで行った作業を自動サマリ

## ログ形式

```markdown
# 業務ログ YYYY/MM/DD

## 実施事項
- [HH:MM] 作業内容1
- [HH:MM] 作業内容2

## 案件進捗
- {案件名}: {進捗内容}

## 次回アクション
- [ ] TODO1
- [ ] TODO2

## メモ
- 備考事項
```
