# ポートフォリオ — ポートフォリオKPIダッシュボード

ポートフォリオ全体のKPIを一覧表示し、アラートを出します。

## やること

1. **portfolio/** 配下の各投資先フォルダから最新財務データを収集
2. 以下のKPIダッシュボードを生成:
   - 売上高（実績 vs 予算、前年比）
   - EBITDA・EBITDAマージン
   - Net Debt / EBITDA
   - フリーキャッシュフロー
   - ROIC
3. アラート判定（以下の閾値でフラグ）:
   - 売上が予算比 ▲10%以上の乖離 → 要注意
   - EBITDAマージンが前年比 ▲3%pt以上悪化 → 要注意
   - Net Debt/EBITDA > 3.0x → 警告
   - コベナンツ抵触の恐れ → 緊急
4. taiga_simのKPIエンジンとの比較（該当する場合）
5. 結果を `ai-management/output/analysis/` に保存

## 出力形式

```
===== ポートフォリオダッシュボード =====
基準日: YYYY/MM/DD

■ 全体サマリ
投資先数: X社 | 総投資額: X,XXX M¥ | 総NAV: X,XXX M¥

■ 個社KPI
| 投資先 | 売上 | 予算比 | EBITDA | マージン | ND/EBITDA | アラート |
|-------|------|-------|--------|---------|----------|---------|

■ アラート
🔴 [緊急] ...
🟡 [要注意] ...
🟢 問題なし: X社
```
