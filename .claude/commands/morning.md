# おはよう — 朝の業務ブリーフィング

以下を実行して、今日の業務概要を生成してください。

## やること

1. **work-log/** の最新ログを確認し、前日までの進捗をサマリ
2. **deals/** 配下のアクティブ案件を一覧化し、各案件の現在フェーズと直近の更新を表示
3. **engagements/** 配下のアクティブFAS案件を一覧化
4. **portfolio/** の最新KPIアラート（あれば）を確認
5. 上記を踏まえ、今日の推奨タスクリストを優先度順で提案

## 出力形式

```
===== 朝のブリーフィング =====
日付: YYYY/MM/DD

■ 前日までの進捗サマリ
- ...

■ アクティブ案件（PE）
| 案件名 | フェーズ | 直近更新 | 次のアクション |
|--------|---------|---------|--------------|

■ アクティブ案件（FAS）
| 案件名 | フェーズ | 直近更新 | 次のアクション |
|--------|---------|---------|--------------|

■ ポートフォリオアラート
- ...

■ 今日の推奨タスク
1. [優先度: 高] ...
2. [優先度: 中] ...
3. [優先度: 低] ...
```
